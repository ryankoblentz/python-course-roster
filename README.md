# Course Roster Manager

This is my final project for **CMP131 - Fundamentals of Programming (Python)** at County College of Morris, completed in Spring 2026.

The program is a command-line application that manages course rosters for two class sections. It reads student information from text files and allows the user to work with the roster through a menu system.

## Features

- Display the current roster for either section
- Add new students to a roster
- Process student withdrawals
- Combine both course rosters
- Search for a student by last name
- Sort course rosters
- Read and write roster information using text files

## Running the Program

Make sure the following files are in the same directory:

- `CourseRoster.py`
- `Enrollments23130.txt`
- `Enrollments20237.txt`

Then run:

```bash
python CourseRoster.py
```

The program will load both sample rosters and display the main menu.

## Sample Data

The original project used course roster data provided for the class assignment. The enrollment files included in this repository have been replaced with **fictional sample data** to protect student privacy.

`CourseRoster.py` is the original version of the program submitted for my CMP131 final project.
